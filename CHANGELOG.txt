ROUND BOOK - RELEASE NOTES
==========================

Newest first. This file is not part of the app and is not loaded by it; it ships alongside the code files.
To add a release: raise APP_VERSION in js/01-data.js and CACHE_NAME in sw.js to the same number, then put a new entry at the top of this list.

Version 2.96
  - The user guide has been rewritten to be shorter and simpler, and its feedback section removed
  - The in-app version history has been removed; release notes now live in this file
    (CHANGELOG.txt), which ships alongside the code

Version 2.95
  - iPad and desktop: lighter, easier-to-read text. Bold weights step down one notch, text uses
    grayscale smoothing (the default on a Mac made it look thick), small grey labels have more
    contrast and the base size is a touch larger. Phones are unchanged

Version 2.94
  - iPad and desktop: the list on the left now scrolls in its own column with its own scrollbar at
    the column edge (it used to use the window scrollbar at the far side of the screen, beside the
    right-hand pane), and the list stays scrollable while something is open on the right

Version 2.93
  - Today: Start and Stop buttons under the big card. Start swaps the tiles for today's to-do list
    (same cards as Rounds > Due, plus today's jobs) with the big card pinned above it and the list
    scrolling underneath; finished customers stay in view and the list moves up from the second one
    on. A 0–100% progress bar sits at the bottom of the big card, and the date above it has gone (it
    is in the header)

Version 2.92
  - Day notes from the Schedule now print on the Monthly Schedule report (a long note is given in
    full under the calendar). On iPad and computer the two columns are switched off while the
    Schedule tab is showing, so nothing from the right-hand pane shows through

Version 2.91
  - New tab layout: Today, Schedule, Work (Rounds / Jobs) and Sales (Quotes / Marketing), with the
    sub tabs pinned under the top and remembering where you were. The Schedule is now its own tab
    and keeps your unsaved changes while you look at other tabs; Reject / Commit are smaller; you
    can leave a note on any day; and a new round can be given a day before its first clean

Version 2.90
  - Live sync: opening the app no longer asks for end-of-day mileage before your other device's
    answer has arrived, and a screen being open can no longer hold sync back while the top says
    Synced. The top now says Update waiting in that case and catches up the moment the screen closes

Version 2.89
  - Pop-ups with a box to type in (such as editing an amount in a history, or the Schedule's
    dialogs) now open at the top so the keyboard can't cover them; a photo's buttons stay pinned at
    the bottom while the photo scrolls underneath

Version 2.88
  - iPad and computer: the empty right-hand pane now shows a summary for the tab you're on; reports
    preview inside it; drag the divider to resize it; right-click menus on cards; hover highlights;
    and keyboard moves through the list (j / k, Enter, C, P)

Version 2.87
  - User guide updated: it now explains the ✓ Cleaned today badge shown on customers cleaned today
    who have no mobile number

Version 2.86
  - Swiping all the way across (cleaned and paid) no longer opens a text; a halfway swipe still
    does. Customers cleaned today who have no mobile number now show a ✓ Cleaned today badge on
    their card too

Version 2.85
  - Under the hood: app updates now install all-or-nothing so the app can never end up half-updated;
    live sync and saving are much lighter on the phone with a big customer list; the photo gallery
    loads a page at a time; email links are made safer; plus 16 more automatic self-checks (add
    ?test to the web address)

Version 2.84
  - Behind the scenes: adding ?test to the end of the web address now runs 50 automatic self-checks
    on the due-date, owing, quote and sync calculations and shows how many passed. Normal use is
    unchanged

Version 2.83
  - Each customer can now have their own Message by choice (default, text or WhatsApp). If someone
    isn't on WhatsApp, tap Not on WhatsApp? on the message screen and they switch to text for good

Version 2.82
  - Colour schemes: Ocean, Rust, Forest and Plum now have calmer, near-neutral backgrounds and a
    contrasting accent colour (coral, cobalt, ochre and teal), the same approach as Slate. Slate and
    High contrast are unchanged

Version 2.81
  - Live sync now uses your Round Book sync service automatically — there is no address to type in

Version 2.80
  - Photo gallery moved from About into the ⋯ menu, next to Reports and Backup, and About is tidier

Version 2.79
  - Schedule: iPad and desktop now open with 5 weeks too, the same as on a phone

Version 2.78
  - Schedule: opens showing 5 weeks instead of 9 (＋ Show 4 more weeks is still there), and Push
    back, Multi, Split and Job now sit behind a ⋯ More… button

Version 2.77
  - Excel, PDF, Word and map tools are now stored with the app itself, so installing no longer
    depends on an outside website
